# ZyberSpace by Ajmal

**Enterprise Technology, Security & Practical Learning**

ZyberSpace is the home for my structured technical knowledge and hands-on learning material. It brings together two complementary areas: **ZyberKnowledge** for maintained technical reference and **ZyberLab** for practical exercises, testing, and guided exploration.

The aim is simple: learn a concept, understand why it matters, test it where practical, document what was learned, and improve it over time.

## Explore ZyberSpace

### ZyberKnowledge

A maintained enterprise technology and security knowledge base covering infrastructure, security engineering, identity and access, detection and response, governance, hardening, implementation guidance, troubleshooting, and engineering practices.

[Explore ZyberKnowledge](https://ajmal-anwar.gitbook.io/zyberspace-by-ajmal/zyberknowledge)

### ZyberLab

A beginner-friendly hands-on lab for building, testing, observing, and understanding technology and security concepts through practical exercises. The environment grows gradually as new learning objectives require additional systems, tools, or controls.

[Explore ZyberLab](https://ajmal-anwar.gitbook.io/zyberspace-by-ajmal/zyberlab)

## How the two areas work together

**ZyberKnowledge** explains the concepts, engineering context, implementation considerations, and operational practices.

**ZyberLab** turns selected concepts into practical exercises that can be built, tested, observed, validated, and documented.

Together they support a practical learning cycle:

**Learn → Build → Test → Validate → Document → Improve**
